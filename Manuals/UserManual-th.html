เกี่ยวกับ NPSeeker

NPSeeker (Nucleic Acid Probe Seeker) เป็นโปรแกรมออกแบบโพรบกรดนิวคลีอิกจากลำดับจีโนม โดยเน้นการคัดเลือกโพรบสำหรับไบโอเซนเซอร์ เช่น BioFET (ทรานซิสเตอร์สนามไฟฟ้าสำหรับการตรวจวัดทางชีวภาพ) โพรบกรดนิวคลีอิกคือสาย DNA สั้น ๆ ที่สามารถจับ กับ DNA ของสิ่งมีชีวิตที่ต้องการตรวจหา เพื่อช่วยในการตรวจจับหรือระบุชนิดสิ่งมีชีวิต

NPSeeker รับจีโนมสองกลุ่ม ได้แก่ กลุ่มเป้าหมาย (target) ซึ่งต้องการตรวจหา และกลุ่มควบคุม (control) ซึ่งไม่ต้องการให้ตรวจพบ โปรแกรมจะค้นหาลำดับ DNA ที่พบร่วมกันในจีโนมเป้าหมายทุกชุด จากนั้นประเมินความคล้ายคลึงกับจีโนมควบคุม ความสามารถในการจับกับลำดับเป้าหมาย และแนวโน้มที่โพรบ จะพับกลับมาจับกับตัวเอง แล้วจัดอันดับโพรบที่เป็นไปได้ตามคะแนน ผู้ใช้กำหนดความยาวโพรบได้ตั้งแต่ 5 ถึง 256 นิวคลีโอไทด์

ผู้เขียนHao-Yu Peng, Hui Zhi Gan, et al.

เกี่ยวกับคู่มือฉบับนี้

หากเพิ่งเริ่มใช้ NPSeeker แนะนำให้เริ่มที่บทที่ 0 หากต้องการใช้ส่วนติดต่อแบบกราฟิก เมื่อทำตามขั้นตอนใน หัวข้อที่ 0.1 ถึง 0.3 เรียบร้อยแล้ว สามารถไปที่หัวข้อ 0.4 ได้โดยตรง การเตรียมไฟล์จีโนมของตนเองอยู่ ในบทที่ 2 และการปรับค่าพารามิเตอร์อยู่ในบทที่ 5

โปรแกรมมีระบบช่วยเหลือในตัว: -h แสดงตัวเลือกที่ใช้บ่อย ส่วน -help แสดงตัวเลือกทั้งหมด คู่มือฉบับนี้ อธิบายขั้นตอน ตัวอย่าง และข้อควรพิจารณาเพิ่มเติม มีทั้งไฟล์ข้อความ (UserManual-th.txt) และ HTML (UserManual-th.html) หรือเปิดอ่านผ่านหน้า Help ในส่วนติดต่อแบบกราฟิกได้

0. เริ่มต้นใช้งาน

เว้นแต่ระบุเป็นอย่างอื่น คำสั่งในคู่มือนี้ใช้รูปแบบของ macOS และ Linux โดยจะระบุคำสั่งสำหรับ Windows เมื่อแตกต่างกัน

หากไม่เคยใช้โปรแกรมผ่านบรรทัดคำสั่งมาก่อน ให้ทำตามหัวข้อนี้ตามลำดับ

0.1 ดาวน์โหลดเวอร์ชันที่เหมาะสม

ดาวน์โหลดไฟล์แพ็กเกจสำหรับระบบปฏิบัติการของคุณจากเว็บไซต์ NPSeeker หรือ GitHub มีแพ็กเกจแยก สำหรับ Windows, macOS และ Linux โดยแต่ละแพ็กเกจมีไฟล์โปรแกรมสำหรับสถาปัตยกรรมตัวประมวลผล สองแบบ:

x86_64ตัวประมวลผล Intel และ AMD ส่วนใหญ่
arm64Mac ที่ใช้ชิป Apple ตระกูล M และคอมพิวเตอร์ระบบ ARM อื่น ๆ

หากไม่แน่ใจว่าคอมพิวเตอร์ใช้สถาปัตยกรรมใด:

  • Windows: เปิด "การตั้งค่า -> ระบบ -> เกี่ยวกับ" แล้วดู "ชนิดของระบบ" หากแสดง x64 หมายถึง x86_64 และ ARM64 หมายถึง arm64
  • macOS: เปิด "เมนู Apple -> เกี่ยวกับ Mac เครื่องนี้" เครื่องที่ใช้ชิป Apple ตระกูล M เป็น arm64 ส่วนเครื่องที่ใช้ Intel เป็น x86_64
  • Linux: เปิดเทอร์มินัล พิมพ์ uname -m แล้วกด Enter หากได้ x86_64 ให้ใช้ x86_64 และหากได้ aarch64 ให้ใช้ arm64

0.2 แตกไฟล์แพ็กเกจ

แตกไฟล์ที่ดาวน์โหลดไว้ลงในโฟลเดอร์ที่ต้องการ:

  • Windows: คลิกขวาที่ไฟล์แพ็กเกจ แล้วเลือก "แยกทั้งหมด" (Extract All)
  • macOS: ดับเบิลคลิกไฟล์แพ็กเกจ
  • Linux: เปิดเทอร์มินัล แล้วใช้คำสั่ง tar xzf ตามด้วยชื่อไฟล์แพ็กเกจ

ในโฟลเดอร์ NPSeeker ที่แตกไฟล์แล้วจะมี:

bin/โปรแกรมสำหรับ x86_64: npseeker (Windows ใช้ npseeker.exe)
bin.arm64/โปรแกรมสำหรับ arm64
doc/คู่มือการใช้งาน
dat/sample/ข้อมูลตัวอย่างสำหรับการทดลองใช้งานครั้งแรก

จีโนมแบคทีเรียที่ใช้ในบทความ NPSeeker (แกรมลบ GN และแกรมบวก GP) มีให้ดาวน์โหลดแยกต่างหาก (NPSeeker-1.5.42-datasets.zip หรือ .tar.gz) สามารถแตกไฟล์ แล้วย้ายโฟลเดอร์ datasets ที่อยู่ข้างใน (ใต้ NPSeeker/dat/) ไปไว้ในโฟลเดอร์ dat ของโปรแกรม เพื่อทดสอบด้วยตัวอย่างคำสั่งในบทที่ 8 ได้ตามที่เขียนไว้

การวิเคราะห์บนเครื่องไม่จำเป็นต้องติดตั้งโปรแกรมหรือเชื่อมต่ออินเทอร์เน็ต ตัวอย่างคำสั่งในคู่มือนี้ใช้ โปรแกรม x86_64 ในโฟลเดอร์ bin/ หากใช้ arm64 ให้เปลี่ยน bin เป็น bin.arm64 ในคำสั่ง

0.3 ตรวจสอบว่าเปิด NPSeeker ได้

เปิดหน้าต่างบรรทัดคำสั่ง แล้วเปลี่ยนไดเรกทอรีไปยังโฟลเดอร์ NPSeeker ที่แตกไฟล์ไว้:

  • Windows: เปิดโฟลเดอร์ NPSeeker ใน File Explorer พิมพ์ cmd ในแถบที่อยู่ แล้วกด Enter หน้าต่าง Command Prompt จะเปิดขึ้นในโฟลเดอร์นั้น สามารถใช้ PowerShell กับคำสั่งเดียวกันได้
  • macOS: เปิด "Terminal" (Applications -> Utilities) พิมพ์ cd ตามด้วยเว้นวรรค แล้วลากโฟลเดอร์ NPSeeker มาวางในหน้าต่าง Terminal จากนั้นกด Enter
  • Linux: เปิดเทอร์มินัลแล้วใช้ cd เพื่อเข้าโฟลเดอร์ NPSeeker

ป้อนคำสั่งสำหรับระบบของคุณ แล้วกด Enter:

Windows:          .\bin\npseeker.exe -h
macOS, Linux:     ./bin/npseeker -h

หากหน้าจอแสดงโลโก้ วิธีใช้ และตัวเลือกพื้นฐาน แสดงว่าโปรแกรมพร้อมใช้งาน

ระบบปฏิบัติการอาจแสดงคำเตือนความปลอดภัยเมื่อเปิดโปรแกรมที่ดาวน์โหลดจากอินเทอร์เน็ตเป็นครั้งแรก หากโปรแกรมไม่มีลายเซ็นดิจิทัล

ก่อนอนุญาตให้เปิดโปรแกรม ตรวจสอบว่าได้ดาวน์โหลดจากเว็บไซต์ NPSeeker หรือ GitHub ที่ระบุในหัวข้อ "เกี่ยวกับ NPSeeker" เท่านั้น อย่าข้ามคำเตือนสำหรับซอฟต์แวร์ที่ไม่ทราบแหล่งที่มา

  • Windows: อาจพบหน้าต่างสีน้ำเงินจาก Microsoft Defender SmartScreen ที่แจ้งว่า Windows ปกป้องพีซีของคุณ และมีเพียงปุ่มไม่ให้เรียกใช้ ให้คลิกตัวเลือกข้อมูลเพิ่มเติม ("More info" ในระบบภาษาอังกฤษ) เพื่อดูชื่อโปรแกรมและข้อมูลผู้เผยแพร่ที่ไม่รู้จัก จากนั้นเลือกให้ เรียกใช้ต่อไป ("Run anyway" ในระบบภาษาอังกฤษ) คำเตือนนี้โดยทั่วไปจะปรากฏเพียงครั้งเดียว สำหรับไฟล์โปรแกรมเดียวกัน
  • macOS: ระบบอาจบล็อกแอปที่ไม่ได้ผ่านการรับรองจาก Apple ใน Terminal ให้ใช้ xattr -dr com.apple.quarantine ตามด้วยตำแหน่งโฟลเดอร์ NPSeeker (ลากโฟลเดอร์มาวางใน Terminal เพื่อใส่ตำแหน่งได้) หรือทดลองเปิด NPSeeker หนึ่งครั้ง แล้วไปที่ "การตั้งค่าระบบ -> ความเป็นส่วนตัวและความปลอดภัย" เลือก "ยืนยันจะเปิด" สำหรับ npseeker
  • Linux: โดยปกติไม่ต้องตั้งค่าเพิ่ม หากพบ "permission denied" ให้ใช้ chmod +x bin/npseeker (หรือ chmod +x bin.arm64/npseeker สำหรับ arm64) แล้วลองใหม่

0.4 ทดลองวิเคราะห์ผ่านส่วนติดต่อแบบกราฟิก

หากไม่ต้องการใช้บรรทัดคำสั่ง NPSeeker มีส่วนติดต่อที่เปิดผ่านเว็บเบราว์เซอร์ได้ บน Windows ให้ดับเบิลคลิก npseeker.exe ใน bin/ สำหรับ macOS หรือ Linux ให้ป้อนคำสั่งต่อไปนี้:

./bin/npseeker --gui

เมื่อหน้าโปรแกรมเปิดในเบราว์เซอร์ ให้ไปที่หน้า Design แล้วทดลองกับข้อมูลตัวอย่างที่แนบมา:

  • Target: เลือก dat/sample/S.aureus/ ซึ่งมีจีโนมของ Staphylococcus aureus หนึ่งชุด
  • Control: เลือก dat/sample/yeast/ ซึ่งมีจีโนมจากยีสต์สองชนิด
  • Probe length: ใช้ค่าเริ่มต้น 25 และไม่ต้องปรับตัวเลือกอื่น
  • คลิก "Check" เพื่อตรวจสอบข้อมูลและการตั้งค่า แล้วคลิก "Go" เพื่อเริ่มวิเคราะห์
  • เมื่อเสร็จแล้ว ไปที่หน้า Results เพื่อดูโพรบที่จัดอันดับพร้อมคะแนน และดาวน์โหลดผลที่ต้องการเก็บไว้

ส่วนติดต่อแบบกราฟิกทำงานบนคอมพิวเตอร์ของคุณเอง ไม่ได้อัปโหลดไฟล์จีโนมไปยังเว็บไซต์ภายนอก ดูรายละเอียดส่วนติดต่อและวิธีออกจากโปรแกรมในบทที่ 6

0.5 ทดลองวิเคราะห์ผ่านบรรทัดคำสั่ง

สามารถวิเคราะห์ข้อมูลตัวอย่างชุดเดียวกันผ่านบรรทัดคำสั่งได้โดยตรง:

Windows:          .\bin\npseeker.exe dat\sample\S.aureus\ dat\sample\yeast\
macOS, Linux:     ./bin/npseeker     dat/sample/S.aureus/ dat/sample/yeast/

โปรแกรมควรทำงานเสร็จภายในไม่กี่วินาที และแสดงรายชื่อโพรบที่เรียงตามคะแนน ดังตัวอย่างบางส่วน:

แต่ละแถวคือโพรบที่เป็นไปได้หนึ่งรายการ คอลัมน์ Probe แสดงลำดับ DNA ส่วน Score คือคะแนนรวม โพรบที่ได้คะแนนสูงจะอยู่ด้านบน ความหมายของคอลัมน์อื่นอธิบายในบทที่ 3 เมื่อจบการทำงานจะมีข้อความ Note เตือนให้ใช้ -o หากต้องการบันทึกผลทั้งหมดลงไฟล์ ตัวอย่างเช่น:

./bin/npseeker dat/sample/S.aureus/ dat/sample/yeast/ -o result/

โปรแกรมจะบันทึกไฟล์ไว้ใน result/ (หัวข้อ 3.2) หากต้องการวิเคราะห์อีกครั้ง ให้เลือกโฟลเดอร์ผลลัพธ์ ใหม่ หรือใช้ -w เมื่อยินยอมให้แทนที่ผลเดิมเท่านั้น หากต้องการใช้จีโนมของตนเอง ให้เปลี่ยนโฟลเดอร์ ตัวอย่างทั้งสองเป็นข้อมูลเป้าหมายและข้อมูลควบคุม (บทที่ 2)

หากระบุตัวเลือกไม่ถูกต้อง NPSeeker จะแจ้งปัญหา พร้อมบอกวิธีเปิดคำอธิบายที่เกี่ยวข้อง และจะไม่เริ่ม วิเคราะห์

1. วิธีที่ NPSeeker ออกแบบและให้คะแนนโพรบ

NPSeeker รับจีโนมเป้าหมายและจีโนมควบคุมเป็นข้อมูลเข้า แล้วสร้างรายชื่อโพรบที่เป็นไปได้ตามลำดับ คะแนน เป้าหมายคือสิ่งมีชีวิตที่ต้องการตรวจพบ ส่วนกลุ่มควบคุมคือสิ่งมีชีวิตที่ไม่ต้องการให้โพรบจับ ซึ่งมักเป็น ชนิดที่ใกล้เคียงและอาจสับสนกับเป้าหมายได้ การวิเคราะห์มีสี่ขั้นตอนหลัก:

  • ค้นหาลำดับที่มีร่วมกัน: โปรแกรมอ่านลำดับนิวคลีโอไทด์ต่อเนื่องทุกช่วงที่ยาว k ตำแหน่ง เรียกว่า k-mer เช่น ACGTA มี 3-mer ได้แก่ ACG, CGT และ GTA ทุก k-mer ที่พบในจีโนมเป้าหมายทุกชุดจะกลายเป็น โพรบที่เป็นไปได้ หากต้องการตรวจเป้าหมายทั้งหมดด้วยโพรบเพียงชนิดเดียว โพรบนั้นต้องมีลำดับร่วมอยู่ใน ทุกเป้าหมาย เนื่องจาก DNA มีสองสายที่เป็นคู่สมกัน NPSeeker จึงถือว่า k-mer กับลำดับคู่สมแบบย้อน กลับ (reverse complement) เป็น k-mer เดียวกัน
  • กรองโพรบที่เป็นไปได้: ตัดลำดับที่ไม่เหมาะสม เช่น มีสัดส่วนเบสไม่สมดุล มีเบสซ้ำติดกันยาวเกินไป (เช่น AAAA) หรือมีแนวโน้มพับกลับมาจับกับตัวเองหรือจับกับโพรบสำเนาอื่น การกรองช่วยลดเวลาที่ต้องใช้ กับลำดับคุณภาพต่ำในขั้นตอนถัดไป
  • ตรวจสอบกลุ่มควบคุม: ค้นหาในจีโนมควบคุมว่ามีลำดับตรงกันทุกตำแหน่ง ลำดับคล้ายกันที่ต่างเพียงไม่กี่เบส หรือชิ้นส่วนสั้น ๆ ของโพรบหรือไม่
  • ให้คะแนนและจัดอันดับ: คำนวณคะแนนสี่องค์ประกอบของแต่ละโพรบ แล้วนำมารวมเป็นคะแนนรวม
Exclusivityพบในเป้าหมาย แต่พบในกลุ่มควบคุมน้อย
Purityมีลำดับคล้ายหรือชิ้นส่วนสั้น ๆ ตรงกับกลุ่มควบคุมน้อย จึงลดความเสี่ยงของการจับกับลำดับที่ไม่ต้องการ
Unfoldabilityมีแนวโน้มพับกลับมาจับกับตัวเองต่ำ จึงเปิดโอกาสให้โพรบจับกับเป้าหมายได้
Affinityความแรงของการจับที่คาดการณ์จากพลังงานอิสระ ของการจับ (พลังงานที่ปลดปล่อยเมื่อโพรบจับเป้าหมาย)

คะแนนแต่ละองค์ประกอบและคะแนนรวมอยู่ระหว่าง 0 ถึง 100 โดยคะแนนสูงแสดงถึงคุณสมบัติที่คาดการณ์ว่าดี กว่า ค่าเริ่มต้นให้น้ำหนักทั้งสี่องค์ประกอบเท่ากัน คะแนนเหล่านี้ช่วยคัดเลือกโพรบไปทดสอบในห้องปฏิบัติการ ไม่ใช่ความแรงสัญญาณ BioFET ที่วัดได้จริง และไม่รับประกันผลการทดลอง

หากจีโนมเป้าหมายแตกต่างกันมากจนมี k-mer ร่วมกันไม่เพียงพอ NPSeeker จะแบ่งจีโนมออกเป็นกลุ่ม แล้วค้นหาโพรบในแต่ละกลุ่มแยกกัน ดูการจัดกลุ่มและโหมดผลลัพธ์ในบทที่ 4 ส่วนสมการคะแนนและรายละเอียด อัลกอริทึมอยู่ในบทความวิจัย

2. การเตรียมจีโนมเป้าหมายและจีโนมควบคุม

อาร์กิวเมนต์สองตัวแรกของบรรทัดคำสั่งคือข้อมูลเป้าหมายและข้อมูลควบคุมตามลำดับ แล้วจึงตามด้วยตัวเลือก:

./bin/npseeker <target> <control> [options]

ให้เตรียมหนึ่งไฟล์ FASTA ต่อหนึ่งจีโนม FASTA เป็นรูปแบบไฟล์ข้อความสำหรับลำดับ DNA โดยทั่วไปใช้ นามสกุล .fasta, .fna หรือ .fa สามารถระบุข้อมูลเป้าหมายและควบคุมแยกกันเป็นโฟลเดอร์ รายการ ไฟล์ หรือไฟล์ FASTA เดี่ยวได้

2.1 ระบุข้อมูลเป็นโฟลเดอร์

เมื่อระบุโฟลเดอร์ NPSeeker จะอ่านเฉพาะไฟล์นามสกุล .fasta, .fna หรือ .fa และถือว่าแต่ละไฟล์ เป็นหนึ่งจีโนม รองรับนามสกุลตัวพิมพ์เล็กทั้งหมดหรือตัวพิมพ์ใหญ่ทั้งหมด เช่น .FASTA โปรแกรมจะไม่ค้นหาใน โฟลเดอร์ย่อย

./bin/npseeker targets/ controls/

ไฟล์บีบอัด (.gz, .zst) ในโฟลเดอร์จะไม่ถูกนำมาวิเคราะห์ หากต้องการใช้ไฟล์ FASTA ที่บีบอัด ให้ระบุผ่านรายการไฟล์แทน

2.2 ระบุข้อมูลด้วยรายการไฟล์

รายการไฟล์เป็นไฟล์ข้อความธรรมดาที่ระบุพาธของไฟล์ FASTA หนึ่งไฟล์ต่อหนึ่งบรรทัด เติม @ หน้าชื่อ รายการ เพื่อบอก NPSeeker ให้เปิดไฟล์นั้นในฐานะรายการไฟล์:

./bin/npseeker @target.list @control.list

ตัวอย่างเนื้อหาใน target.list:

# Three target genomes
genomes/strain_A.fasta
genomes/strain_B.fna.gz
/data/others/strain_C.fa
  • บรรทัดว่างและบรรทัดที่เริ่มด้วย # จะถูกข้าม จึงสามารถใช้เขียนหมายเหตุได้
  • พาธสัมพัทธ์จะอ้างอิงจากไดเรกทอรีที่เรียก NPSeeker ไม่ใช่ไดเรกทอรีที่เก็บไฟล์รายการ
  • ไฟล์ในรายการอาจอยู่คนละโฟลเดอร์ และรองรับ FASTA ที่บีบอัดด้วย gzip (.gz) หรือ zstd (.zst)
  • เมื่อใช้ -cluster-order input ลำดับไฟล์ในรายการจะกำหนดลำดับการประมวลผลเพื่อจัดกลุ่ม (บทที่ 4)

หากระบุไฟล์ที่ไม่ใช่นามสกุล FASTA โดยไม่มี @ โปรแกรมจะตีความเป็นรายการไฟล์เช่นกัน แต่แนะนำให้เติม @ เพื่อระบุเจตนาให้ชัดเจน

2.3 ระบุไฟล์ FASTA เดี่ยว

หากกลุ่มเป้าหมายหรือกลุ่มควบคุมมีเพียงหนึ่งจีโนม สามารถส่งไฟล์ FASTA ให้ NPSeeker ได้โดยตรง และใช้ไฟล์ FASTA ที่บีบอัดได้ด้วย:

./bin/npseeker strain_A.fasta controls/

2.4 เนื้อหา FASTA และการตรวจสอบข้อมูลเข้า

  • ไฟล์ FASTA หนึ่งไฟล์อาจมีหลายระเบียนลำดับ เช่น โครโมโซมและพลาสมิด ทุกระเบียนในไฟล์เดียวกันถือ เป็นหนึ่งจีโนม
  • NPSeeker รับเบส A, C, G และ T ทั้งตัวพิมพ์ใหญ่และเล็ก ตัวอักษรอื่น เช่น N จะทำให้ลำดับขาดช่วง และไม่รวม k-mer ที่คร่อมตำแหน่งดังกล่าว
  • NPSeeker ตรวจสอบรูปแบบ FASTA ของไฟล์ข้อมูลเข้า หากไฟล์หายไปหรือไม่ถูกต้อง โปรแกรมจะหยุด พร้อมข้อความผิดพลาด (หัวข้อ 7.2)
  • ไฟล์เดียวกันห้ามอยู่ทั้งในกลุ่มเป้าหมายและกลุ่มควบคุม หากพบไฟล์ซ้ำ โปรแกรมจะแจ้งและหยุดทำงาน

การเลือกจีโนมเป้าหมายและจีโนมควบคุมมีผลโดยตรงต่ออันดับของโพรบ ควรใช้จีโนมควบคุมจากสิ่งมีชีวิตที่ มีโอกาสถูกสับสนกับเป้าหมายจริง มากกว่าการเลือกชนิดที่ไม่เกี่ยวข้องกันโดยไม่มีเหตุผล

3. การอ่านผลและการคัดเลือกโพรบ

3.1 ผลลัพธ์ที่แสดงบนหน้าจอ

หากไม่ใช้ -o โปรแกรมจะแสดงโพรบอันดับสูงสุดจำนวน -top รายการ (ค่าเริ่มต้น 200) บนหน้าจอ โดยมี Rank, Probe, คะแนนองค์ประกอบทั้งสี่, Score และ Tm หากใช้ -o โปรแกรมจะบันทึกผลโดยละเอียดลง ไฟล์ และแสดงชื่อไฟล์ที่บันทึกไว้แทน เพิ่ม -v เพื่อดูการตั้งค่าและเวลาที่ใช้ในแต่ละขั้นตอน

3.2 ไฟล์ผลลัพธ์

ตัวอย่างเช่น -o result/ จะบันทึกผลในรูปแบบ CSV (ค่าที่คั่นด้วยจุลภาค) เป็นค่าเริ่มต้น:

cluster_N_probes.csvรายชื่อโพรบตามอันดับ โดย N คือเลขกลุ่มเริ่มจาก 0
cluster.csvการจัดกลุ่มของแต่ละจีโนม

หากต้องการตารางข้อความที่จัดคอลัมน์ด้วยช่องว่างและอ่านได้ง่าย ให้ใช้ -format txt ไฟล์ CSV เหมาะกับการเปิดใน Excel หรือโปรแกรมอื่น จำนวนไฟล์โพรบขึ้นกับโหมด single หรือ multi (บทที่ 4)

ไฟล์ cluster.csv มีสามคอลัมน์: Group (target หรือ control), Cluster (เลขกลุ่มของเป้าหมาย เว้นว่างสำหรับกลุ่มควบคุม) และ File (ชื่อไฟล์) ส่วน flag.csv มีคอลัมน์ Option และ Value เพื่อให้ตรวจสอบการตั้งค่าที่ใช้ได้

หากโฟลเดอร์ผลลัพธ์ยังไม่มี โปรแกรมจะสร้างให้ และใช้โฟลเดอร์ที่มีอยู่แต่ยังว่างได้เช่นกัน หากมีไฟล์อยู่แล้ว โปรแกรมจะหยุดเพื่อป้องกันการเขียนทับ ใช้ -w เฉพาะเมื่อต้องการแทนที่ผลเดิม โดย NPSeeker จะลบเฉพาะไฟล์ผลลัพธ์ของ NPSeeker ที่มีอยู่ก่อน (cluster_N_probes, cluster และ flag) แต่เก็บไฟล์อื่นที่ไม่เกี่ยวข้องไว้ ควรตรวจสอบว่าไม่ต้องการผลเดิมแล้วก่อนใช้ -w

3.3 แนวทางคัดเลือกโพรบ

Score เป็นจุดเริ่มต้นที่ดีในการจัดอันดับ แต่ไม่ควรใช้คะแนนรวมเพียงอย่างเดียว ควรพิจารณาข้อมูลอื่นตาม ลักษณะงานด้วย:

  • Ctl: ถ้ามากกว่า 0 แสดงว่ามีลำดับเดียวกันทุกเบสอยู่ในจีโนมควบคุม จึงอาจเกิดการจับกับสิ่งมีชีวิตนอก เป้าหมาย (cross-reactivity)
  • Tgt: หากพบหลายตำแหน่งอาจให้สัญญาณแรงขึ้น แต่ก็อาจเป็นบริเวณลำดับซ้ำ Tgt ไม่ใช่ตัวทำนายความ แรงสัญญาณโดยตรง
  • Purity และ UnFold: ช่วยเปรียบเทียบความเสี่ยงจากการจับผิดเป้าหมายและการพับกลับมาจับกับตัวเอง
  • Tm: หากการทดลองมีข้อจำกัดเรื่องอุณหภูมิหรือใช้โพรบหลายชนิดร่วมกัน ควรเปรียบเทียบอุณหภูมิหลอมเหลว และควรเลือกโพรบที่มีค่า Tm ใกล้เคียงกัน

ผู้ใช้สามารถตรวจสอบโพรบกับ NCBI BLAST เพื่อค้นหาลำดับคล้ายในสิ่งมีชีวิตอื่น หรือใช้ UNAFold (mfold) ประเมินโครงสร้างการพับตัว หน้า Results มีลิงก์ไปยังบริการทั้งสอง แต่จะส่งลำดับโพรบที่เลือก ไปยังเว็บไซต์ภายนอก (หัวข้อ 6.2) สุดท้ายต้องทดสอบโพรบภายใต้สภาวะการทดลองจริง จึงจะทราบว่า เหมาะกับแพลตฟอร์ม BioFET ที่ใช้หรือไม่

4. การจัดกลุ่มจีโนมเป้าหมายและโหมด single/multi

หากจีโนมเป้าหมายมี k-mer ร่วมกันน้อยเกินไป NPSeeker จะจัดจีโนมเป็นกลุ่ม (cluster) โดยพิจารณาที ละจีโนม จีโนมใหม่จะเข้ากลุ่มปัจจุบันได้ก็ต่อเมื่อจำนวน k-mer ที่พบร่วมกันในสมาชิกทุกชุดรวมถึงจีโนมใหม่นั้น ยังไม่น้อยกว่า -min-shared มิฉะนั้นจะเลื่อนไปจัดในกลุ่มถัดไป กลุ่มเหล่านี้ใช้เพื่อค้นหาโพรบ ไม่ใช่การจัด จำแนกทางวิวัฒนาการหรือสายสัมพันธ์เชิงวิวัฒนาการ

ตัวเลือก -cluster-order กำหนดลำดับการพิจารณาจีโนมเป้าหมาย:

  • auto (ค่าเริ่มต้น): เลือกลำดับอย่างแน่นอนตามความคล้ายของ k-mer ระหว่างจีโนม การสลับลำดับไฟล์ ข้อมูลเข้าจะไม่เปลี่ยนการจัดกลุ่ม หากเป็นชุดจีโนมเดิม
  • input: ใช้ลำดับที่ผู้ใช้ระบุ เช่น ลำดับในไฟล์รายการ เหมาะเมื่อต้องการให้จีโนมอ้างอิงที่กำหนดเป็นจุด เริ่มของกลุ่มแรก

ค่าเริ่มต้นของ -min-shared คือ 1 หมายความว่าจีโนมใหม่เข้ากลุ่มได้หากสมาชิกทุกชุดยังมี k-mer ร่วมกันอย่างน้อยหนึ่งรายการ ดังนั้นเป้าหมายมักรวมเป็นกลุ่มเดียว การเพิ่มค่านี้อาจทำให้เกิดหลายกลุ่มและ เปลี่ยนชุดโพรบที่เป็นไปได้ในแต่ละกลุ่ม

เมื่อมีจีโนมเป้าหมายมากกว่าหนึ่งกลุ่ม -mode จะกำหนดวิธีจัดอันดับและบันทึกโพรบ:

  • single (ค่าเริ่มต้น): รวมโพรบจากทุกกลุ่มเป็นอันดับชุดเดียว แล้วเก็บเฉพาะ -top อันดับแรกทั้งหมดใน cluster_0_probes.csv โพรบอันดับสูงหลายรายการอาจมาจากกลุ่มเดียวกัน
  • multi: จัดอันดับแต่ละกลุ่มแยกกัน และเก็บได้สูงสุด -top รายการต่อกลุ่ม ลงใน cluster_0_probes.csv, cluster_1_probes.csv เป็นต้น เหมาะเมื่อต้องการโพรบสำหรับทุก กลุ่มเป้าหมาย

ในโหมด multi การเลือกโพรบจากทุกกลุ่มทำให้ได้ชุดโพรบที่ครอบคลุมกลุ่มเป้าหมายทั้งหมดในเชิงคำนวณ แต่ประสิทธิภาพการตรวจจับจริงยังต้องพิสูจน์ด้วยการทดลอง ตรวจสอบสมาชิกของแต่ละกลุ่มใน cluster.csv หากไม่เหลือโพรบที่ผ่านการกรองในกลุ่มใด NPSeeker จะแจ้งคำเตือน แต่ยังบันทึกผลของกลุ่มอื่น

5. ตัวเลือกและพารามิเตอร์

ให้ใส่ตัวเลือกหลังอาร์กิวเมนต์ target และ control ตัวเลือกที่ต้องระบุค่าให้เว้นวรรคก่อนค่า เช่น -k 31 ส่วนตัวเลือกเปิด/ปิดอย่าง -v, -w และ --gui ไม่ต้องมีค่า บางตัวเลือกมีชื่อย่อและชื่อเต็ม เช่น -k และ -kmer สามารถใช้แทนกันได้ ตัวเลขรองรับรูปแบบวิทยาศาสตร์ เช่น 1e7 หมายถึง 10,000,000 หัวข้อด้านล่างเรียงตามหมวดของผลลัพธ์ -help โดยชื่อในวงเล็บของแต่ละหัวข้อคือชื่อหมวดใน -help และมีตารางสรุปในภาคผนวก A

5.1 ความยาวโพรบและทรัพยากรคอมพิวเตอร์ (General settings)

-k, -kmer [จำนวนเต็ม 5 ถึง 256; ค่าเริ่มต้น: 25]

กำหนดความยาวโพรบเป็นจำนวนนิวคลีโอไทด์ ให้เลือกตามความต้องการของการทดลอง เมื่อ k เพิ่มขึ้น จีโนมเป้าหมายที่แตกต่างกันมากจะมีโอกาสพบลำดับยาวเท่ากันร่วมกันน้อยลง และอาจต้องแบ่งเป็นหลายกลุ่ม เวลาทำงานขึ้นกับขนาดจีโนมและจำนวนโพรบที่เป็นไปได้เป็นหลัก โพรบที่ยาวกว่าไม่ได้ใช้เวลามากกว่าเสมอ ไป (ดูรูปที่ 4 ในบทความ)

-t, -threads [จำนวนเต็ม; ค่าเริ่มต้น: 0]

กำหนดจำนวนเธรดทำงาน ค่า 0 ใช้ฮาร์ดแวร์เธรดที่มีทั้งหมด หากยังต้องใช้คอมพิวเตอร์ทำงานอื่นร่วมด้วย ให้ลดจำนวนเธรด

-m, -memory [ขนาดหน่วยความจำ; ค่าเริ่มต้น: ครึ่งหนึ่งของ RAM สูงสุด 8G]

กำหนดงบประมาณหน่วยความจำสำหรับขั้นตอนคำนวณหลัก เช่น -m 8G หรือ -m 512M หากไม่ใส่หน่วย โปรแกรมจะตีความเป็น GiB การกำหนดหน่วยความจำน้อยลงทำให้ต้องประมวลผลเป็นชุดย่อยมากขึ้นและอาจ ช้าลง แต่ไม่เปลี่ยนผลวิเคราะห์ หน่วยความจำสำหรับโหลดโพรบเป็นชุดตาม -b และข้อมูลอื่นขณะทำงานจะ เพิ่มจากงบประมาณนี้ (หัวข้อ 5.5)

5.2 ผลลัพธ์และบันทึกการทำงาน (Output)

-o, -out-dir [โฟลเดอร์; ค่าเริ่มต้น: ไม่บันทึกไฟล์ผลลัพธ์]

ระบุโฟลเดอร์ที่จะเก็บไฟล์ผลลัพธ์ (หัวข้อ 3.2) หากไม่ใช้ -o โปรแกรมจะแสดงผลบนหน้าจอโดยมีคอลัมน์ น้อยกว่า แนะนำให้บันทึกไฟล์หากต้องการเก็บผล เปรียบเทียบ หรือทำการวิเคราะห์ซ้ำในภายหลัง

-w, --overwrite

อนุญาตให้ใช้โฟลเดอร์ -o ที่มีไฟล์อยู่แล้ว โดยจะลบไฟล์ผลลัพธ์ NPSeeker ก่อนหน้าออกก่อนเขียนไฟล์ใหม่ แต่ไม่ลบไฟล์อื่น (หัวข้อ 3.2)

-top [จำนวนเต็ม; ค่าเริ่มต้น: 200]

กำหนดจำนวนโพรบอันดับสูงสุดที่จะส่งออกในแต่ละชุดการจัดอันดับ เพิ่มค่านี้หากต้องการดูโพรบมากขึ้น แต่ค่าที่สูงมากจะทำให้ไฟล์ใหญ่ขึ้น และอาจต้องใช้หน่วยความจำและเวลามากขึ้น

-format [csv หรือ txt; ค่าเริ่มต้น: csv]

กำหนดรูปแบบไฟล์ผลลัพธ์ csv เป็นค่าที่คั่นด้วยจุลภาค เหมาะกับตารางคำนวณและโปรแกรมอื่น ส่วน txt เป็นตารางที่จัดคอลัมน์ด้วยช่องว่าง อ่านได้โดยตรง

-v, --verbose

แสดงรายละเอียดเพิ่มเติม เช่น ข้อมูลเข้า การตั้งค่า ขั้นตอนประมวลผล และเวลาที่ใช้ในแต่ละขั้นตอน ใช้ติดตามงานที่ใช้เวลานานหรือแก้ปัญหา การวิเคราะห์ที่เริ่มจากส่วนติดต่อแบบกราฟิกจะใช้บันทึกละเอียดนี้ เสมอ

5.3 การจัดกลุ่มและจัดอันดับ (Target clustering, Probe ranking)

-cluster-order [auto หรือ input; ค่าเริ่มต้น: auto]

กำหนดลำดับที่ใช้จัดกลุ่มจีโนมเป้าหมาย auto ไม่ขึ้นกับลำดับไฟล์ข้อมูลเข้า ส่วน input ใช้ลำดับที่ระบุไว้ ดูรายละเอียดและกรณีใช้งานในบทที่ 4

-min-shared [จำนวนเต็ม; ค่าเริ่มต้น: 1]

กำหนดจำนวน k-mer ขั้นต่ำที่ต้องพบร่วมกันในสมาชิกทุกจีโนมของกลุ่ม การเพิ่มเกณฑ์นี้โดยทั่วไปทำให้มีหลาย กลุ่มขึ้น แต่ไม่ได้รับประกันว่าทุกกลุ่มจะได้โพรบที่เหมาะสม (บทที่ 4)

-mode [single หรือ multi; ค่าเริ่มต้น: single]

สองโหมดนี้ให้ผลต่างกันเฉพาะเมื่อเป้าหมายมีหลายกลุ่ม single รวมโพรบของทุกกลุ่มเป็นรายการอันดับเดียว ส่วน multi สร้างรายการอันดับแยกแต่ละกลุ่ม ดูแนวทางเลือกโหมดในบทที่ 4

-weights [KEY=WEIGHT คั่นด้วยจุลภาค; ค่าเริ่มต้น: ทุกองค์ประกอบเท่ากับ 1]

ปรับน้ำหนักของ Exclusivity (exc), Purity (pur), Unfoldability (unf) และ Affinity (aff) ในคะแนนรวม ตัวอย่าง:

-weights exc=2,pur=2

ตัวอย่างนี้ให้น้ำหนัก Exclusivity และ Purity เป็นสองเท่าของเดิม ส่วน unf กับ aff ยังมีน้ำหนัก 1 คะแนนรวมคำนวณดังนี้:

Score = (w_exc*Exclus + w_pur*Purity + w_unf*UnFold + w_aff*Affini)
        / (w_exc + w_pur + w_unf + w_aff)

น้ำหนักเป็นศูนย์ได้ แต่เป็นค่าลบไม่ได้ และต้องมีอย่างน้อยหนึ่งองค์ประกอบที่น้ำหนักมากกว่าศูนย์ องค์ประกอบที่ น้ำหนักศูนย์ยังถูกคำนวณตามปกติ เพียงแต่ไม่ส่งผลต่อ Score การเพิ่มน้ำหนักเปลี่ยนลำดับคะแนน ไม่ใช่การก รองโพรบที่ได้คะแนนองค์ประกอบนั้นต่ำ

-mm, -mismatch-cutoff [จำนวนเต็ม; ค่าเริ่มต้น: ปัดลงของ k/10]

กำหนดจำนวนเบสที่แตกต่างกันสูงสุดในการค้นหาลำดับที่คล้ายกับโพรบในจีโนมควบคุม เพื่อใช้คำนวณ Purity ค่าที่สูงขึ้นตรวจพบลำดับคล้ายได้มากขึ้น แต่อาจเพิ่มเวลาและหน่วยความจำอย่างมาก เกณฑ์นี้ต้องน้อยกว่า ความยาวโพรบ

5.4 การกรองโพรบที่เป็นไปได้ (Candidate filtering)

NPSeeker กรองโพรบก่อนเข้าสู่ขั้นตอนเปรียบเทียบกับจีโนมควบคุมที่ใช้ทรัพยากรมากกว่า หากกำหนดเกณฑ์ เข้มงวดเกินไป อาจไม่เหลือโพรบผ่านการกรอง จึงอาจต้องผ่อนปรนค่าต่อไปนี้

-max-homopolymer [จำนวนเต็ม; ค่าเริ่มต้น: 3]

Homopolymer คือช่วงที่นิวคลีโอไทด์ชนิดเดียวกันเรียงต่อกัน เช่น AAAA ตัวเลือกนี้กำหนดจำนวนเบสซ้ำติดกัน สูงสุดที่อนุญาต ค่าเริ่มต้น 3 ยอมรับ AAA แต่ตัดโพรบที่มี AAAA หรือยาวกว่า การเพิ่มเกณฑ์ทำให้เก็บโพรบที่มี เบสซ้ำมากขึ้น

-c, -min-complexity [จำนวน 0 ถึง 1; ค่าเริ่มต้น: 0.5]

กำหนดคะแนนความซับซ้อนของลำดับขั้นต่ำ หากมีสัดส่วนของนิวคลีโอไทด์ทั้งสี่ชนิดสมดุลกัน คะแนนจะสูงขึ้น โพรบต้องได้คะแนนสูงกว่าเกณฑ์จึงจะผ่าน

-e, -min-entropy [จำนวน 0 ถึง 2; ค่าเริ่มต้น: 1.5]

กำหนดคะแนน entropy ของลำดับขั้นต่ำ ซึ่งใช้วัดความหลากหลายของลำดับ รูปแบบซ้ำ เช่น ACACAC มี entropy ต่ำ โพรบต้องได้คะแนนสูงกว่าเกณฑ์จึงจะผ่าน โพรบสั้นมีคะแนนสูงสุดที่เป็นไปได้ของ complexity และ entropy ต่ำกว่า หากระบุเกณฑ์ที่สูงกว่าค่าสูงสุดของความยาวที่เลือก NPSeeker จะแจ้งข้อผิดพลาด พร้อมค่าสูงสุดที่ทำได้

-prefilter [T หรือ F; ค่าเริ่มต้น: T]

กำหนดว่าจะกรองโพรบตาม Unfoldability ก่อนตรวจจีโนมควบคุมหรือไม่ T ตัดโพรบที่ได้คะแนนต่ำกว่า -min-unfold เพื่อลดงานเปรียบเทียบ ส่วน F ข้ามการกรองขั้นต้นนี้ แต่โปรแกรมยังคำนวณคะแนน Unfoldability ให้ทุกโพรบ

-min-unfold [จำนวน 0 ถึง 100; ค่าเริ่มต้น: 75]

กำหนดเกณฑ์คะแนน Unfoldability ที่ใช้ในการกรองขั้นต้น การลดค่านี้ช่วยเก็บโพรบที่อาจพับตัวเองได้มาก ขึ้น แต่อาจเพิ่มงานในขั้นต่อไป หากโพรบในชุดหนึ่งไม่มีรายการใดผ่านเกณฑ์ NPSeeker จะข้ามการกรองขั้น ต้นสำหรับชุดนั้น ตัวอย่างเช่น โพรบของแบคทีเรียแกรมบวกที่ทดลองในบทความมีคะแนน Unfoldability เท่ากับ 72.54 จึงต้องใช้ -min-unfold 70 เพื่อทำซ้ำการจัดอันดับ (บทที่ 8)

5.5 ตัวเลือกขั้นสูง (Advanced)

ค่าเริ่มต้นเหมาะสมกับการใช้งานส่วนใหญ่

-b, -batch-size [จำนวนเต็ม; ค่าเริ่มต้น: 1e7]

กำหนดจำนวน k-mer ที่เป็นไปได้ที่โหลดและกรองต่อชุด เมื่อ k = 25 แต่ละรายการใช้หน่วยความจำ ประมาณ 170 ไบต์ ดังนั้นค่าเริ่มต้น 10 ล้านรายการใช้ประมาณ 1.58 GiB เพิ่มจากงบประมาณ -m หากเครื่องมีหน่วยความจำน้อย ให้ลดค่านี้ แต่ชุดที่เล็กลงอาจทำให้การวิเคราะห์ช้าลง

-s, -min-subseq [จำนวนเต็ม; ค่าเริ่มต้น: 7]

กำหนดความยาวขั้นต่ำของชิ้นส่วนโพรบที่นำมาคำนวณคะแนน Purity ใช้ร่วมกับ -subseq-step

-subseq-step [จำนวนเต็ม; ค่าเริ่มต้น: ปัดขึ้นของ k/10]

กำหนดขนาดที่ลดลงของความยาวชิ้นส่วนในแต่ละรอบของการคำนวณ Purity ตัวอย่างเช่น เมื่อ k = 25 ค่าเริ่มต้นเท่ากับ 3 จึงตรวจความยาว 22, 19, 16, 13, 10 และ 7 การลดค่าช่วงนี้ทำให้ตรวจหลาย ความยาวขึ้น และเพิ่มปริมาณงานเปรียบเทียบ

-tmp-dir [โฟลเดอร์; ค่าเริ่มต้น: โฟลเดอร์ชั่วคราวของระบบ]

กำหนดที่เก็บไฟล์ระหว่างประมวลผล NPSeeker จะสร้างโฟลเดอร์ย่อยของตัวเองที่นี่ และลบเมื่อทำงานเสร็จ ตามปกติหรือถูกขัดจังหวะด้วย Ctrl-C หากดิสก์ระบบมีพื้นที่ไม่พอ ให้เลือกโฟลเดอร์บนดิสก์อื่น

5.6 ส่วนติดต่อแบบกราฟิกและวิธีใช้ (Graphical interface)

--guiเปิดส่วนติดต่อแบบกราฟิกในเครื่อง แทนการวิเคราะห์จากบรรทัดคำสั่งโดยตรง
-gui-port [จำนวนเต็ม] ค่าเริ่มต้น: เลือกให้อัตโนมัติพอร์ตที่รับการเชื่อมต่อ (เลขหลัง : ใน URL)
--no-browserแสดง URL โดยไม่เปิดเบราว์เซอร์
--tabเปิดส่วนติดต่อในแท็บของเบราว์เซอร์
-hแสดงวิธีใช้อย่างย่อ
-help [KEYWORD]แสดงวิธีใช้ทั้งหมด หรือเฉพาะตัวเลือกหรือหมวด

--gui ใช้ร่วมกับ -gui-port, --no-browser และ --tab เท่านั้น ให้ตั้งค่าการวิเคราะห์ เช่น -k ภายในส่วนติดต่อ หากป้อนพร้อม --gui ในบรรทัดคำสั่ง โปรแกรมจะแจ้งข้อผิดพลาด ดูรายละเอียดในบทที่ 6

6. ส่วนติดต่อแบบกราฟิก

NPSeeker เปิดเว็บเซิร์ฟเวอร์ขนาดเล็กบนคอมพิวเตอร์ของคุณ โดยเข้าถึงได้เฉพาะเครื่องนั้น (127.0.0.1) และใช้เว็บเบราว์เซอร์เป็นส่วนติดต่อ ตัวโปรแกรม NPSeeker เป็นผู้ประมวลผลข้อมูล ไฟล์จีโนมจะไม่ถูกอัปโหลดไปยังเว็บไซต์ภายนอก เมื่อใช้การตั้งค่าเดียวกัน ส่วนติดต่อแบบกราฟิกกับบรรทัด คำสั่งจะให้ผลลัพธ์เหมือนกัน

6.1 เปิดโปรแกรมและเชื่อมต่อ

  • Windows: ดับเบิลคลิก npseeker.exe ใน bin/ หรือใช้ .\bin\npseeker.exe --gui ผ่าน Command Prompt โปรแกรมจะเปิดหน้าต่างคอนโซลสีดำที่แสดงข้อความการทำงาน ให้เปิดหน้าต่างนี้ค้าง ไว้ระหว่างใช้ส่วนติดต่อ
  • macOS, Linux: ใช้คำสั่ง ./bin/npseeker --gui ในเทอร์มินัล

โดยปกติ NPSeeker จะเปิดเบราว์เซอร์อัตโนมัติ และแสดง URL ของส่วนติดต่อด้วย เช่น:

http://127.0.0.1:53817/?t=1a2b3c...

ข้อความหลัง ?t= คือโทเคนสำหรับเข้าถึงเซสชันปัจจุบัน หากเบราว์เซอร์ไม่เปิดอัตโนมัติ ให้คัดลอก URL ทั้งหมดไปวางในเบราว์เซอร์ อย่าแชร์ URL นี้โดยไม่จำเป็น เพราะมีโทเคนสำหรับเข้าใช้งาน

ค่าเริ่มต้นจะเปิดส่วนติดต่อในหน้าต่างแยก เบราว์เซอร์ Edge และ Chrome ใช้หน้าต่างลักษณะคล้ายแอปโดย ไม่มีแถบที่อยู่ ส่วน Firefox เปิดหน้าต่างใหม่ หากต้องการให้เปิดเป็นแท็บในเบราว์เซอร์เริ่มต้น ให้ใช้ --tab

6.2 หน้าหลักของส่วนติดต่อ

Designเลือกจีโนม Target และ Control รวมถึงโฟลเดอร์ผลลัพธ์ (ไม่บังคับ) และความยาวโพรบ เลือกได้ทั้งโฟลเดอร์หรือ ไฟล์ FASTA รายไฟล์ รวมถึงไฟล์บีบอัดจากหลายตำแหน่ง "Tick all" เลือกไฟล์ทั้งหมดในโฟลเดอร์ ส่วน "Pick folder" และ "Pick files" เปิดหน้าต่างเลือกไฟล์ ของระบบปฏิบัติการ ขยายตัวเลือกเพิ่มเติมเมื่อต้องการ ช่องที่เว้นว่างจะใช้ค่าเริ่มต้น "Check" ตรวจสอบข้อมูล และการตั้งค่า ส่วน "Go" เริ่มวิเคราะห์
Runแสดงขั้นตอนปัจจุบัน ความคืบหน้า และบันทึกการทำงาน "Cancel" ใช้หยุดการวิเคราะห์
Resultsดูโพรบที่จัดอันดับ ลำดับเบส และคะแนนต่าง ๆ คลิกหัวคอลัมน์เพื่อจัดเรียง โดยคอลัมน์ Rank เก็บอันดับเดิมจาก NPSeeker คลิกโพรบเพื่อดู ลำดับคู่สมแบบย้อนกลับและอุณหภูมิหลอมเหลว หรือคัดลอกลำดับ ดาวน์โหลดไฟล์ทีละไฟล์หรือรวมเป็น ZIP
Helpอ่านคู่มือและเปลี่ยนภาษา
Aboutดูข้อมูลโปรแกรม บทความ ผู้เขียน และการติดต่อ

หน้า Results ยังมีลิงก์ไปยังบริการภายนอกสองรายการ:

  • BLAST at NCBI: เปิด NCBI BLAST พร้อมลำดับโพรบที่เลือก เพื่อค้นหาลำดับคล้ายกันในสิ่งมีชีวิตอื่น
  • Fold at UNAFold: ส่งลำดับไปยัง UNAFold (mfold) เพื่อทำนายการพับตัวของ DNA โดยใช้ การตั้งค่าเริ่มต้นในแบบฟอร์มบนเว็บไซต์ (37 °C, 1 M Na+)

บริการทั้งสองต้องเชื่อมต่ออินเทอร์เน็ตและส่งลำดับโพรบที่เลือกไปยังเว็บไซต์ภายนอก หากเป็นลำดับที่ยัง ไม่เผยแพร่ ให้ตรวจสอบก่อนว่าการส่งข้อมูลดังกล่าวเหมาะสมหรือได้รับอนุญาต

หากไม่กำหนดโฟลเดอร์ผลลัพธ์ ส่วนติดต่อแบบกราฟิกจะเก็บผลไว้ชั่วคราวในดิสก์ของเครื่อง และลบเมื่อออก จากส่วนติดต่อ ต้องดาวน์โหลดไฟล์ที่ต้องการเก็บก่อนออกจากโปรแกรม

6.3 ปิดหน้าเว็บ ออกจากโปรแกรม และเก็บผลลัพธ์

  • "Close" ปิดเฉพาะหน้าเว็บเบราว์เซอร์ แต่ NPSeeker ยังทำงานอยู่ หากต้องการกลับไปใช้งาน ให้เปิด URL ที่แสดงในคอนโซลอีกครั้ง
  • "Exit" ปิดส่วนติดต่อและหยุดการวิเคราะห์ที่ยังดำเนินอยู่ การปิดหน้าต่างคอนโซลหรือกด Ctrl-C จะออกจากโปรแกรมเช่นกัน
  • หากปิดหน้าเว็บทั้งหมดไว้นานเกินห้านาทีและไม่มีการวิเคราะห์อยู่ NPSeeker จะปิดตัวเองโดยอัตโนมัติ และลบผลลัพธ์ชั่วคราวที่ยังไม่ได้ดาวน์โหลด

เมื่อคลิก "Exit" หรือ "Close" ส่วนติดต่อจะขอให้ยืนยัน และแจ้งเตือนหากมีงานที่กำลังทำหรือมีผลลัพธ์ ชั่วคราวที่ยังไม่ได้ดาวน์โหลด

หากกำหนดโฟลเดอร์ผลลัพธ์ไว้แล้ว ไฟล์จะคงอยู่ในโฟลเดอร์นั้น เมื่อสั่งวิเคราะห์ใหม่โดยใช้โฟลเดอร์เดิม โปรแกรมจะแทนที่ไฟล์ผลลัพธ์ NPSeeker เดิม แต่ไม่ลบไฟล์อื่น

สามารถเลือกธีม Auto, Dark หรือ Light หากเลือก Auto ส่วนติดต่อจะใช้รูปลักษณ์สว่างหรือมืดตาม การตั้งค่าระบบปฏิบัติการ

6.4 ใช้ส่วนติดต่อบนเซิร์ฟเวอร์ระยะไกล

หาก NPSeeker ทำงานบนเซิร์ฟเวอร์ระยะไกล สามารถใช้ส่วนติดต่อผ่านเบราว์เซอร์บนเครื่องของคุณโดย สร้าง SSH tunnel ซึ่งเป็นการเชื่อมต่อแบบเข้ารหัสที่ส่งต่อพอร์ตในเครื่องไปยังเซิร์ฟเวอร์ เริ่มจากเปิด NPSeeker บนเซิร์ฟเวอร์พร้อมกำหนดพอร์ต:

./bin/npseeker --gui --no-browser -gui-port 53817

จากนั้นเปิดเทอร์มินัลบนคอมพิวเตอร์ของคุณ แล้วสร้าง SSH tunnel:

ssh -L 53817:127.0.0.1:53817 username@server

เปิดการเชื่อมต่อ SSH ค้างไว้ แล้วป้อน URL ทั้งหมดที่ NPSeeker แสดงบนเซิร์ฟเวอร์ในเบราว์เซอร์ของ เครื่องคุณ หากต้องการเปลี่ยนพอร์ตฝั่งเครื่องตัวเอง เช่น:

ssh -L 9000:127.0.0.1:53817 username@server

ให้เปลี่ยนส่วนต้นของ URL เป็น http://127.0.0.1:9000/ และเก็บโทเคน ?t= เดิมไว้

เมื่อใช้ผ่านเซิร์ฟเวอร์ระยะไกล ส่วนติดต่อจะเรียกดูไฟล์บนเซิร์ฟเวอร์ ไม่ใช่ในคอมพิวเตอร์ของคุณ "Pick folder" และ "Pick files" ก็เปิดหน้าต่างเลือกไฟล์บนเซิร์ฟเวอร์ หากเซิร์ฟเวอร์ไม่มีเด สก์ท็อปแบบกราฟิก จะใช้หน้าต่างเหล่านี้ไม่ได้ ให้ใช้ตัวเรียกดูไฟล์ที่มีอยู่ภายในส่วนติดต่อแทน

6.5 ที่เก็บไฟล์การตั้งค่า

NPSeeker เก็บโฟลเดอร์ที่เคยใช้ล่าสุดใน recent.txt และตำแหน่งที่เลือกล่าสุดใน lastpick.txt เพื่ออำนวยความสะดวกในครั้งถัดไป ไฟล์ขนาดเล็กสองไฟล์นี้อยู่ที่:

Linux~/.config/npseeker/
macOS~/Library/Application Support/npseeker/
Windows%AppData%\npseeker\

ไฟล์ระหว่างประมวลผลอยู่ในโฟลเดอร์ชั่วคราวของระบบหรือพาธที่ระบุด้วย -tmp-dir ไม่ได้อยู่ในโฟลเดอร์ ตั้งค่าข้างต้น

7. ประสิทธิภาพและการแก้ไขปัญหา

7.1 หน่วยความจำ เวลา และไฟล์ชั่วคราว

  • หน่วยความจำ: -m จำกัดหน่วยความจำสำหรับขั้นตอนคำนวณหลัก แต่การโหลดโพรบทีละชุดตาม -b และข้อมูลอื่นขณะทำงานต้องใช้หน่วยความจำเพิ่มเติม หากหน่วยความจำไม่เพียงพอ ให้ลดทั้ง -m และ -b
  • เธรด: -t 0 ใช้ฮาร์ดแวร์เธรดทั้งหมด หากใช้คอมพิวเตอร์ทำงานอื่นด้วย ให้ลดค่านี้
  • เวลา: ขึ้นกับขนาดจีโนม จำนวนโพรบที่พบร่วมกัน ค่า -mm หน่วยความจำ ฮาร์ดแวร์ และความเร็วดิสก์ การเพิ่ม k ไม่จำเป็นต้องทำให้งานช้าลง ใช้ -v เพื่อตรวจเวลาของแต่ละขั้นตอน
  • ไฟล์ชั่วคราว: NPSeeker สร้างไฟล์ระหว่างวิเคราะห์ ขนาดไฟล์ขึ้นกับข้อมูลและงบประมาณหน่วยความจำ หากให้งบประมาณหน่วยความจำน้อยลง โดยทั่วไปจะต้องมีพื้นที่ดิสก์ชั่วคราวมากขึ้น ควรตรวจสอบพื้นที่ว่าง โปรแกรมจะลบไฟล์ชั่วคราวเมื่อทำงานเสร็จตามปกติ หรือถูกขัดจังหวะด้วย Ctrl-C

7.2 ข้อความผิดพลาดที่พบบ่อย

ข้อความเมื่อระบุตัวเลือกหรือพารามิเตอร์ไม่ถูกต้องขึ้นต้นด้วย "npseeker:" ส่วนข้อผิดพลาดเกี่ยวกับข้อมูล เข้า ผลลัพธ์ หรือการทำงานขึ้นต้นด้วย "Error:" ตัวอย่างต่อไปนี้แสดงปัญหาที่พบบ่อยและวิธีแก้ไข หากข้อความใช้ control แทน target แสดงว่าปัญหาเกิดกับข้อมูลกลุ่มควบคุม

  • Error: target: no FASTA file (*.fasta, *.fna or *.fa) in the folder ...
    ไม่พบไฟล์นามสกุล FASTA ที่รองรับในโฟลเดอร์ หากเป็นไฟล์บีบอัดให้ใช้รายการไฟล์ (หัวข้อ 2.2)
  • Error: target: "..." is not found
    พาธไม่ถูกต้อง โดยพาธสัมพัทธ์อ้างอิงจากโฟลเดอร์ที่เรียกโปรแกรม
  • Error: target: "..." is not a FASTA file: ...
    รูปแบบไฟล์ไม่ใช่ FASTA ที่ถูกต้อง รายละเอียดสาเหตุอยู่หลังเครื่องหมาย :
  • Error: target: the FASTA file "...", listed in "...", is not found
    ไม่พบไฟล์ที่ระบุไว้ในรายการไฟล์
  • Error: target and control: ...; a genome cannot be both a target and a control
    มีไฟล์เดียวกันอยู่ทั้งในกลุ่มเป้าหมายและกลุ่มควบคุม
  • Error: -o: the folder "..." already exists and is not empty; give -w ...
    โฟลเดอร์ผลลัพธ์มีไฟล์อยู่แล้ว ให้เลือกโฟลเดอร์ใหม่ หรือใช้ -w เมื่อแน่ใจว่าสามารถแทนที่ผลเดิมได้
  • npseeker: option -mm: must be less than the probe length (-k)
    ค่า -mm ต้องน้อยกว่าความยาวโพรบ
  • npseeker: option -c: no probe of 8 nt has a complexity score above 0.431 ...
    เกณฑ์สูงกว่าคะแนนที่เป็นไปได้สำหรับความยาวโพรบที่เลือก (ตัวอย่างนี้สูงสุด 0.431) ให้ลดเกณฑ์ (หัวข้อ 5.4)
  • Error: -tmp-dir: cannot create the folder "...": ...
    โปรแกรมสร้างโฟลเดอร์ชั่วคราวไม่ได้ ให้ตรวจสอบพาธและสิทธิ์การเขียน

7.3 เอาต์พุตมาตรฐานและเอาต์พุตข้อผิดพลาด

ข้อความในเทอร์มินัลมาจากช่องทางสองแบบ ได้แก่ standard output (stdout) และ standard error (stderr) โดยปกติทั้งสองแสดงบนหน้าจอ แต่จะต่างกันเมื่อเปลี่ยนปลายทางเอาต์พุตไปยังไฟล์ เช่น เติม > out.txt ในคำสั่ง ข้อมูล stdout จะลงไฟล์ ส่วน stderr ยังแสดงบนหน้าจอ

NPSeeker ส่งผลลัพธ์ บันทึกรายละเอียดจาก -v และข้อความผิดพลาดไปยัง stdout ส่วนข้อความที่ขึ้นต้น ด้วย Note: คำเตือนที่ขึ้นต้นด้วย Warning: และแถบความคืบหน้าไปยัง stderr จึงสามารถบันทึกผลลงไฟล์ โดยไม่ปะปนข้อความแสดงความคืบหน้า และยังเห็นคำเตือนบนหน้าจอ

7.4 ไม่พบโพรบหรือประมวลผลช้า

หากไม่มีโพรบผ่านการกรอง NPSeeker จะแสดง:

Warning: no probe passed the filters; relax the thresholds
         (-max-homopolymer, -c, -e, -min-unfold) to let probes pass.

ลองผ่อนปรน -min-unfold, -c, -e หรือ -max-homopolymer (หัวข้อ 5.4) หากจีโนมเป้าหมายมี k-mer ร่วมกันน้อยมาก ให้ลองลด -k หรือปรับ -min-shared และ -mode (บทที่ 4) ใช้ -v เพื่อดู จำนวนโพรบที่เหลือและเวลาที่ใช้ในแต่ละขั้นตอน

หากประมวลผลช้าผิดปกติ ให้ตรวจสอบว่าหน่วยความจำที่ต้องใช้สำหรับ -m, การโหลดชุดโพรบตาม -b และงานอื่นไม่เกิน RAM ที่มี มิฉะนั้นระบบปฏิบัติการอาจย้ายข้อมูลจากหน่วยความจำไปยังดิสก์ ทำให้ช้าลงมาก หากกำหนด -mm สูง ให้ลองใช้ค่าเริ่มต้นเพื่อเปรียบเทียบ สำหรับข้อมูลขนาดใหญ่ ควรตรวจความเร็วดิสก์และ พื้นที่ว่างในโฟลเดอร์ชั่วคราวด้วย

8. ตัวอย่างการใช้งาน

ตัวอย่างเหล่านี้ใช้ไวยากรณ์ของ macOS และ Linux บน Windows ให้เปลี่ยน ./bin/npseeker เป็น .\bin\npseeker.exe และใช้ \ แทน / ในพาธ แต่ละตัวอย่างเรียกทำงานแยกกันได้ หาก result/ มีผลลัพธ์จากครั้งก่อน ให้เปลี่ยนโฟลเดอร์ผลลัพธ์ หรือใช้ -w เมื่อยอมรับการแทนที่ผลเดิมเท่านั้น

วิเคราะห์ข้อมูลตัวอย่างและบันทึกไว้ใน result/:

./bin/npseeker dat/sample/S.aureus/ dat/sample/yeast/ -o result/

อ่านจีโนมเป้าหมายจากรายการไฟล์และจัดกลุ่มตามลำดับในรายการ:

./bin/npseeker @target.list controls/ -cluster-order input -o result/

ออกแบบโพรบยาว 31 นิวคลีโอไทด์ด้วย 32 เธรดและหน่วยความจำ 16 GiB:

./bin/npseeker targets/ controls/ -k 31 -t 32 -m 16G -o result/

เพิ่มน้ำหนัก Exclusivity และ Purity ในคะแนนรวม:

./bin/npseeker targets/ controls/ -weights exc=2,pur=2 -o result/

ค้นหาโพรบแยกสำหรับจีโนมเป้าหมายหลายกลุ่ม:

./bin/npseeker targets/ controls/ -min-shared 20000 -mode multi -o result/

ทำซ้ำการจัดอันดับโพรบแบคทีเรียในตารางที่ 3 ของบทความ โดยใช้พารามิเตอร์ของงานวิจัยที่แตกต่างจากค่า เริ่มต้น (ชุดข้อมูลมีให้ดาวน์โหลดแยกต่างหาก ดูวิธีจัดวางในหัวข้อที่ 0.2):

./bin/npseeker dat/datasets/GP/ dat/datasets/GN/ -k 23 -min-unfold 70 \
    -weights exc=2,pur=2 -o GP_probes/
./bin/npseeker dat/datasets/GN/ dat/datasets/GP/ -k 23 -min-unfold 70 \
    -weights exc=2,pur=2 -o GN_probes/

ค่า -min-unfold 70 ช่วยเก็บโพรบแบคทีเรียแกรมบวกที่ทดสอบในการทดลอง ซึ่งมีคะแนน Unfoldability 72.54 ตัวอักษร \ ท้ายบรรทัดของคำสั่งใน macOS และ Linux หมายถึงคำสั่งยังต่อใน บรรทัดถัดไป บน Windows Command Prompt ใช้ ^ ส่วน PowerShell ใช้เครื่องหมาย backtick (`) หรือป้อนทั้งคำสั่งในบรรทัดเดียว

ชุดข้อมูลในบทความส่วนหนึ่งมาจากฐานข้อมูลจีโนมของ ATCC (ATCC Genome Portal) ซึ่งข้อกำหนดการใช้งานไม่อนุญาตให้แจกจ่ายต่อ ดังนั้น dat/datasets/ จึงมีข้อมูลที่สอดคล้องกันจาก NCBI แทน และไฟล์ dat/datasets/sources.txt แสดงการจับคู่แต่ละไฟล์กับชุดข้อมูลในบทความ เมื่อใช้ข้อมูลนี้ ลำดับเบสและอันดับของโพรบทั้งสองในตารางที่ 3 ตรงกับบทความทุกประการ แต่จำนวนตัวเลือก จำนวนครั้งที่พบ และคะแนนต่าง ๆ จะแตกต่างเล็กน้อย ในจำนวนนี้ S. enterica ATCC 43976 มีเพียงแอสเซมบลีที่ไม่สมบูรณ์ใน NCBI (ขาด 23S rRNA ไปบางส่วน) หากไม่เลือกจีโนมนี้เมื่อใช้ GN เป็นเป้าหมาย (ยกเลิกการเลือกในส่วนติดต่อแบบกราฟิก หรือใช้รายการไฟล์ @dat/datasets/GN-without-43976.list ในบรรทัดคำสั่ง) จำนวนตัวเลือกจะกลับเป็น 65 และโพรบ 8 อันดับแรกในตารางเสริม S3 ก็จะตรงกับบทความ

บันทึกผลเป็นตารางข้อความที่อ่านง่าย และส่งออกโพรบมากขึ้น:
